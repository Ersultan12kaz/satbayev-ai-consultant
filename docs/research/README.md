# Исследование (Этап 1): технологии и принятые решения

| Тема | Что изучили | Что выбрали в проекте |
|---|---|---|
| RAG | ответ LLM опирается на найденные фрагменты документов, а не на «память» модели | поиск по официальным документам и сайтам Satbayev University, ответ только по найденным фрагментам, иначе Википедия (только об университете) или «не найдено» |
| LLM | трансформер-декодер (GPT), предобучение + дообучение на инструкциях | собственная GPT 42.1 M параметров, BPE-токенизатор 32 000, предобучение ≈1.2 млрд токенов (perplexity 20.3 на валидации), дообучение на примерах «вопрос → документы → ответ»; ответ принимается только после проверок |
| Embeddings | LSA, контрастивное обучение (InfoNCE), subword-модели для казахского | собственный subword-энкодер 256 измерений: LSA + дообучение InfoNCE на ≈30 000 пар |
| Vector DB | FAISS, pgvector, Chroma | pgvector в Docker, numpy-индекс локально |
| Поиск | dense, BM25, гибрид, реранкинг | гибрид (эмбеддинги + BM25) + обученный реранкер: Recall@5 0.873, MRR 0.759 |
| Multilingual NLP | определение языка, морфология казахского, перевод | собственный детектор языка (точность на вопросах 100 %), поддержка казахского без казахских букв и смешанного каз+рус, собственный переводчик Transformer 52 M (chrF 56.4) |
| Hallucination | faithfulness, отказ при отсутствии ответа | классификатор темы, порог уверенности поиска, проверка чисел и фактов по документам: faithfulness 0.998, отказ на вопросы вне темы 100 % |
